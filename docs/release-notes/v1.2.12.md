## POS System v1.2.12 — แก้ใบเสร็จพิมพ์ไม่ครบ + กันยอดรับเงินผิดปกติ

### 🧾 ใบเสร็จ
- แก้ใบเสร็จที่พิมพ์ออกมาแล้วข้อความหลุดขอบขวา ไม่มีคอลัมน์จำนวน/รวม และข้อความติดกัน (เช่น "ยอดรวมสุทธิ117")
- หน้าตัวอย่างบนจอกับใบที่พิมพ์ออกมาใช้แบบเดียวกันแล้ว เห็นแบบไหนก็ได้แบบนั้น
- เพิ่มตัวเลือก **ตั้งค่า → ตั้งค่าใบเสร็จ → ขนาดกระดาษเครื่องพิมพ์ใบเสร็จ** (58 มม. / 80 มม., ค่าเริ่มต้น 58 มม.)
- ปุ่ม "พิมพ์" หลังทำรายการสำเร็จ ใช้ใบเสร็จแบบเดียวกัน มีชื่อร้าน/ที่อยู่ครบ
- ตัวหนังสือบนใบเสร็จเป็นสีดำทั้งหมด อ่านชัดบนกระดาษความร้อน และไม่ต้องใช้อินเทอร์เน็ตโหลดฟอนต์

### 🛡️ หน้าชำระเงิน
- ถ้าเผลอสแกนบาร์โค้ดเข้าช่อง "รับเงินมา" (ยอดเงินทอนเกิน 100,000 บาท) ระบบจะไม่บันทึก แจ้งเตือน และล้างช่องให้ใส่ใหม่
- เงินทอนตั้งแต่ 1,000 บาทขึ้นไป ต้องกดยืนยันซ้ำอีกครั้ง

อัปเดตผ่าน **ตั้งค่า → ตรวจสอบอัปเดต** หรือดาวน์โหลดตัวติดตั้ง Windows ด้านล่าง
