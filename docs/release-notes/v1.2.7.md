## 🛠️ POS System v1.2.7 — แพตช์แก้บั๊ก + ปกป้องข้อมูลร้าน

อัปเดตนี้เน้น **ความปลอดภัยของข้อมูล** และ **แก้บั๊ก** ไม่มีการเปลี่ยนหน้าตาหรือวิธีใช้งาน
ข้อมูลสินค้า ต้นทุน กำไร บิลขาย และผู้ใช้ **อยู่ครบเหมือนเดิม** และระบบจะสำรองข้อมูลให้อัตโนมัติก่อนติดตั้ง

---

### 🗄️ ใหม่: ระบบกันข้อมูลหาย
- **สำรองก่อนอัปเดต** — กดติดตั้งอัปเดตแล้ว ระบบจะบันทึกข้อมูลที่ค้างอยู่และสำรองไว้ก่อนเสมอ (`before-update-*.db`) ถ้าสำรองไม่สำเร็จจะถามก่อนว่าจะอัปเดตต่อหรือไม่
- **สำรองหลังอัปเดต** — เปิดเวอร์ชันใหม่ครั้งแรก ระบบสำรองอีกชุด (`pre-update-v1.2.6-to-v1.2.7-*.db`)
- **สำรองรายวัน** — เก็บไฟล์สำรองแยกวัน (`auto-YYYY-MM-DD.db`) ย้อนหลัง 14 วัน (เดิมมีไฟล์เดียวที่ถูกเขียนทับทุกครั้ง)
- **สำรองก่อนกู้คืน** — กู้คืนข้อมูลผิดไฟล์ก็ย้อนกลับได้
- **สำรองก่อนลบสินค้าจำนวนมาก** — ถ้าการบันทึกจะลบสินค้าเกินครึ่ง ระบบสำรองไว้ก่อน
- **ตรวจไฟล์ฐานข้อมูลทุกครั้งที่เปิด** — ถ้าพบความเสียหายจะแจ้งเตือนและไม่สำรองทับไฟล์สำรองที่ดี
- **ปุ่ม "เปิดโฟลเดอร์ไฟล์สำรอง"** ในหน้าตั้งค่า และหน้าต่างกู้คืนเปิดที่โฟลเดอร์สำรองให้ทันที
- ถ้าโฟลเดอร์สำรองที่เลือกไว้ใช้ไม่ได้ (เช่น ถอด USB) จะสำรองลงโฟลเดอร์ปกติแทน

### 🐞 แก้บั๊ก
- **หน้าใบเสร็จเด้ง error** — เปิดดูใบเสร็จในหน้า "บิลขาย" แล้วเจอหน้าจอ error เมื่อร้านตั้งเบอร์โทรไว้
- **บิลที่เพิ่งขายอาจหาย** — ถ้าปิดโปรแกรมหรือกดอัปเดตภายใน ~2 วินาทีหลังขาย ตอนนี้ระบบบันทึกให้ก่อนปิดเสมอ
- **จอลูกค้าบันทึกข้อมูลเก่าทับ** — จอลูกค้าเป็นหน้าจอแสดงผลอย่างเดียวแล้ว ไม่บันทึกข้อมูล
- **อ่านฐานข้อมูลไม่ได้แล้วข้อมูลอาจถูกล้าง** — ระบบจะไม่บันทึกข้อมูลว่างทับข้อมูลจริงอีกต่อไป
- **กู้คืนข้อมูลแล้วถูกข้อมูลเก่าเขียนทับ** — ล็อกการบันทึกจนกว่าจะรีสตาร์ท และรีสตาร์ทได้ถูกต้อง
- **หน้าตั้งค่าเริ่มต้นล้างข้อมูลร้านได้** — ป้องกันไม่ให้ทำงานซ้ำหลังตั้งค่าร้านแล้ว
- **ยอดเงินเพี้ยนเศษสตางค์** — ปัดยอดรวมและเงินทอนเป็นทศนิยม 2 ตำแหน่ง
- **นำเข้าผู้ใช้จากไฟล์** — แจ้งจำนวนรายการที่นำเข้าไม่สำเร็จให้เห็นชัดเจน
- **แจ้งเตือนอัปเดต** — แสดงข้อความสถานะถูกต้อง และแสดง release notes เป็นข้อความล้วน (ปลอดภัยขึ้น)
